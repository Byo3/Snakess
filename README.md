# Snakess-Fangame-
Snake... It's all.

It's an MVP from Snake, it not contains a single sprite.

It might contain some bugs, such as apples that are spawned Out-of-bounds,
due to spawn logic, which was built using the STL, the method in question is *random*.

The image below shows an example of the game.

The green one is the snake and the red one is the apple.
This project was Built with SFML library.
